# Session 3

## Goal of today's lesson

Today we will save a square's position in variables.

## What students will learn

- Variables
- X and Y coordinates
- Reusing information

## New words

**Variable:** A labelled box where we keep information.

**Coordinate:** An address on the screen. X goes sideways; Y goes up and down.

**Value:** The information inside a variable.

## Code walkthrough

At the top of `main.py`, `square_x`, `square_y`, and `square_size` are three labelled boxes. Their values replace the hard-to-change numbers from Session 2. The rectangle line uses those boxes in its position tuple. All the other lines still initialise Pygame, handle closing, paint, and update the window. Changing one variable changes the drawing without changing the recipe.

## Challenge

Start the square in the top-left corner.

## What should happen

The same square appears, but its address and size now have friendly names.

## Teacher Tips

Common mistake: mixing up X and Y. Ask: “Which variable moves the square right?” Mini recap: variables make code easier to read and change.
